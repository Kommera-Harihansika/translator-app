# 🌍 AI Translator App

A modern language translation web application built using **React + Vite** and powered by the **Groq API**.

Users can translate text between multiple languages with a simple and responsive interface.

---

## 🚀 Features

- Translate text between multiple languages
- Fast AI-powered translations using Groq
- Clean and responsive UI
- Language selection dropdowns
- Swap source and target languages
- Real-time translation results
- Built with React and Vite

---

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Kommera-Harihansika/translator-app.git
```

### Navigate to project

```bash
cd translator-app
```

### Install dependencies

```bash
npm install
```

### Create environment file

Create a `.env` file in the root directory:

```env
VITE_GROQ_API_KEY=YOUR_GROQ_API_KEY
```

### Run the application

```bash
npm run dev
```

---

## 🔑 Getting a Groq API Key

1. Create an account at Groq.
2. Generate an API key.
3. Add the key to your `.env` file.

---

## 📸 Application Workflow

1. Enter text.
2. Select source language.
3. Select target language.
4. Click Translate.
5. View the translated output instantly.
